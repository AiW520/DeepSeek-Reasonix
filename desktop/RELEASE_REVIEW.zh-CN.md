# 桌面端发布检查

检查日期：2026-09-06。范围：当前 Windows 工作区的桌面 React 前端、桌面 Go 短测试及核心服务抽查。

## 判断

适合邀请少量用户试用，还不能据此认定面向所有用户的正式版本已完成验收。

工程基础较完整：原生桌面壳与核心引擎分离，有权限、检查点、更新验证和大量回归测试。主要不足是新增工作台模块的界面一致性、国际化和异步状态处理，以及发布前真实环境验证。

## 本轮修复

- 工作台第二排卡片原来会把底部文字挤出边框。合并重复样式，取消固定卡片高度，放大主要文字，按内容区实际宽度排列，补齐键盘焦点样式。
- 首次配置弹窗增加矮窗口滚动、焦点循环、错误后聚焦、重复提交保护及输入错误关联。
- 小说工作室直接打开时缺少共享容器样式，首页会遮挡操作。补齐样式依赖，并处理窄窗口的编辑区、项目选择和 AI 操作入口。
- 小说保存竞态已在隔离浏览器中复现：A 的保存响应覆盖后输入的 B；900 毫秒内关闭工作室时没有保存。现使用顺序写入队列，合并同章最新草稿，忽略过期响应，保留失败草稿以重试。
- 切换章节、项目、侧栏工作台、关闭工作室及点击 Windows 窗口关闭按钮前等待保存。导出、恢复、生成章节等操作也先完成待保存写入。浏览器刷新有未保存提示；强制终止进程不属于正常关闭保证。
- 后台章节刷新不会覆盖正在编辑或保存期间产生的新状态。
- 修复两个过期测试契约：PNG 资源导入，以及设置界面重构后的选中供应商分组引用。

小说修复方案已由用户选择：

| 方案 | 实现复杂度 | 运行性能 | 扩展性 | 维护难度 | 潜在坑点 |
| --- | --- | --- | --- | --- | --- |
| 修复保存机制（已采用） | 中 | 单写入队列，减少重复写入 | 按项目、章节隔离，可添加保存入口 | 中，有竞态测试保护 | 原生退出、断电和后台任务仍需真实环境验收 |
| 暂时隐藏小说入口 | 低 | 基本无额外开销 | 后续仍须修复保存机制 | 低 | 用户暂时无法使用小说功能 |

## 验证结果

- 前端发现式测试：198 个套件全部通过。
- 前置测试通过，覆盖终端、监控、用量、输入菜单和会话滚动等；部分现有 React 测试有 `act(...)` 警告。
- 生产构建通过：Hooks、类型、CSS、滚动单写入规则及包体积门禁。
- 核心 Go 抽查通过：`internal/serve`、`internal/permission`、`internal/checkpoint`。
- 桌面 Go 短测试通过：`go test -short -timeout=10m .`，耗时约 273 秒。首次 4 分钟超时未作为代码失败结论。
- Playwright + Edge：1440×1000、1024×768、760×480、390×844 的首页与配置弹窗验证通过。窄屏验证不代表承诺提供移动客户端。
- 六个工作台入口能够打开并返回，检查期间没有浏览器运行错误。
- 小说延迟保存、连续编辑、章节切换、失败重试、关闭工作室、侧栏跳转及 Windows 关闭按钮的模拟绑定回归通过。

新增可复用验证脚本：

```powershell
# 先用 Node 24、pnpm 10 启动桌面前端开发服务器。
$env:REASONIX_UI_REVIEW_URL = 'http://127.0.0.1:5187'
$env:REASONIX_BROWSER_CHANNEL = 'msedge'
node bench/onboarding-workbench.mjs
node bench/novel-save-recovery.mjs
```

## 正式发布前

1. 在安装包中使用真实账号走完配置、对话、工具审批、图片生成、PPT 导出、小说连续创作与导出。浏览器使用模拟数据，本轮没有调用付费生成服务。
2. 验证原生关闭、Alt+F4、托盘退出、重启、断网和磁盘写入失败。模拟绑定覆盖窗口按钮，不能替代原生生命周期验收。
3. 验证签名安装、升级与旧数据兼容；macOS 和 Linux 未在本机验收。
4. 完成新增工作台模块的国际化。当前部分界面直接使用中文字符串，切换 English 后仍会混杂中文。
5. 保持性能预算：首屏 JavaScript gzip 约 425 KiB，已接近 426 KiB 门禁；主要样式约 114.8 KiB，也接近当前预算。后续功能优先延迟加载，避免继续扩大首屏。

本轮未修改真实用户配置、未提交 Git、未发布安装包。
